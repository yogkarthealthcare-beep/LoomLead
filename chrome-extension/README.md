# LoomLead B2B Lead Capturer - Chrome Extension (Manifest V3)

Capture leads directly from **LinkedIn Profiles**, **Google Search / Maps**, and **any B2B company website** straight into LoomLead CRM with automated deduplication and lead scoring.

---

### Features
1. **Zero-Friction Ingestion:** Instantly extracts visible contact name, company, email, phone number, website, and context.
2. **Strict Privacy First:** Only captures data on the active tab when the user clicks the extension. **No background scraping or hidden web monitoring.**
3. **Automatic Deduplication & Hygiene:** If the lead or phone number already exists, LoomLead intelligently merges new details without creating duplicates.
4. **Live Score Preview:** Instantly displays the lead's evaluated score badge (🔥 Hot, ☀️ Warm, ❄️ Cold) right inside the extension.

---

### How to Install (Takes 30 seconds)
1. Open Google Chrome, Brave, or Microsoft Edge.
2. Navigate to `chrome://extensions/` (or `edge://extensions/`).
3. Turn on the **"Developer mode"** toggle in the top-right corner.
4. Click **"Load unpacked"**.
5. Select the `chrome-extension` folder inside the LoomLead project directory.
6. The **LoomLead Capturer** icon will appear in your Chrome toolbar!

---

### Configuration & Login
1. Click the LoomLead icon in your browser toolbar.
2. If disconnected, click the **⚙️ (Settings)** icon.
3. Enter your LoomLead API Key (`ll_live_...`), which can be generated under **LoomLead CRM > Integrations & API**.
4. Click **Save Connection**.
5. Visit any website or LinkedIn profile, click the extension, review the pre-filled fields, and click **"Save to LoomLead CRM"**!
